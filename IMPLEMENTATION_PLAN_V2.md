# ERP System Update & Bug Fixes Plan

## 1. Core Bug Fixes
* **Supplier/Client Debt Sync Bug:** 
  * **Issue:** Advance payments (overpayments) were ignored by a flawed `max(0, ...)` logic when receiving orders, causing the database `debt_amount` to drift from the actual ledger.
  * **Fix:** Remove manual addition/subtraction logic from `PurchaseOrderController` and `SalesController`. Force the system to call `$supplier->recalculateDebt()` and `$client->recalculateDebt()` immediately after *any* order creation, update, cancellation, or payment. This guarantees the DB column and the mathematical ledger are permanently synced.

## 2. Production & Operations
* **Production Order Storage Filter:** 
  * Modify `InventoryController::getProducts` to calculate and return a dedicated `stock_wshp` variable (Stock in WSH-P). 
  * Update `ProductionOrderForm.jsx` so the maximum allowed quantity and the displayed available stock rely exclusively on `stock_wshp` instead of the global total.
* **Used Materials in Production PDF:** 
  * Ensure the backend eager-loads `operationProducts.product.materials`.
  * Add a new column "الخامات المستخدمة" (Used Materials) to the PDF generated by `ProductionOrderCard.jsx`. It will multiply product quantity by BOM requirements, or display `-` if none are used.

## 3. UI/UX Improvements
* **Custom Searchable Dropdowns:**
  * Build a custom `SearchableSelect` React component tailored to the ERP's `#2F264C` dark theme.
  * Replace the native `<select>` tags in major forms to allow fast-searching through hundreds of clients, products, or materials.
  * *Fixing the Default Option Bug:* This custom component will explicitly fire the `onChange` event even if the user clicks the currently selected default/placeholder option, fixing the "must choose 2nd then 1st" bug.
* **Client/Supplier Debt Modal Height:**
  * Add `max-h-[90vh]` and `overflow-y-auto` to `PayDebtModal.jsx` and `SettleDebtModal.jsx`. This ensures the popup becomes scrollable internally instead of overflowing off the top/bottom of small screens.
* **Materials Page Pagination Search:**
  * Move the search filter logic to the backend (`MaterialController::index`) using SQL `LIKE`.
  * Update `materials/page.jsx` to pass the search term to the API with a 500ms debounce, ensuring the search applies to the entire database, not just the first 20 items.
* **Products Statistics Category Filter:**
  * Update the `/products/stats` endpoint to accept an optional `category_id`.
  * Add a category dropdown inside the Statistics Modal (`products/page.jsx`) to recalculate total revenue/profit/COGS for specific categories.

## 4. PDFs and Communication
* **Supplier/Client Statement PDF:**
  * In `SupplierCard.jsx`, replace the signature text `"اعتماد إدارة الورشة والختم"` with `"اعتماد إدارة المصنع"`.
  * Add a "WhatsApp Share" button next to the print button. It will open `https://wa.me/2[Phone]` to instantly start a chat with the client/supplier (users will still manually attach the printed PDF in WhatsApp Web).

## 5. New Feature: Wasted Materials Management (هالك التصنيع)
* **Virtual Waste Storage:** 
  * Ensure `WSH-WASTE` (مخزن الهالك) exists in the database as a standard warehouse.
* **Waste Logging:** 
  * Add an optional "تسجيل هالك المواد" section in the Complete Production (إنهاء التشغيل) popup.
  * When logged, the backend creates a `Production_Waste` movement (deducting from `WSH-M`) and a `Waste_Receipt` movement (adding to `WSH-WASTE`).
* **Waste Analytics:** 
  * Users can navigate to the Inventory page and filter by `WSH-WASTE` to view exact quantities and total financial losses of wasted materials.
* **Recycling / Quick Transfer:** 
  * Unlock the "Quick Transfer" (نقل سريع) button for *Materials* inside the `warehouses/page.jsx` view. This allows users to easily transfer usable scrap materials from `WSH-WASTE` back to `WSH-M`.
* **Selling Scrap:**
  * Update the Sales Invoice form (`SalesController` and frontend) to allow selling both "Products" and "Materials". This lets users sell scrap directly from `WSH-WASTE` to a client, generating revenue.
